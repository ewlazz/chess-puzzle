# 한 수 — 체스 퍼즐

브라우저에서 바로 풀 수 있는 체스 전술 퍼즐 사이트입니다. 메이트부터 포크, 핀, 스큐어, 발견 공격, 언더프로모션까지 12개의 퍼즐이 들어 있어요.

## 기능

- 클릭 또는 드래그로 수 두기, 둘 수 있는 칸 표시
- 둘 차례인 쪽이 아래로 오도록 보드 자동 회전
- 여러 수짜리 퍼즐은 정답을 두면 상대가 자동으로 응수
- 힌트, 정답 보기, 처음부터, 이전/다음 퍼즐
- 폰 승진 시 기물 선택
- 해결한 퍼즐 수, 연속 정답, 최고 연속 기록 (브라우저에 저장)
- 퍼즐 목록 필터(메이트 / 기물 이득 / 안 푼 퍼즐), 전술 사전, 사용법

## 실행

빌드 과정이 없습니다. `index.html`을 브라우저로 열면 됩니다.
GitHub Pages에서 `main` 브랜치의 루트(`/`)를 게시하면 그대로 웹사이트가 됩니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 페이지, 스타일, 퍼즐 데이터와 게임 로직 |
| `pieces.css` | 체스 기물 그림 (SVG 데이터) |

## 퍼즐 추가하기

`index.html`의 `PUZ` 배열에 항목을 추가하세요.

```js
{fen:"6k1/5ppp/8/8/8/8/5PPP/3R2K1 w - - 0 1", sol:["Rd8#"], title:"백랭크 메이트", theme:"메이트", kind:"mate", goal:"1수 메이트", lv:"쉬움"}
```

- `fen`: 시작 포지션
- `sol`: 정답 수순(SAN). 내 수와 상대 응수를 번갈아 적습니다.
- `kind`: `mate` 또는 `win` (목록 필터에 사용)
